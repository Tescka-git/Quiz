# Index des expériences

Les fiches conservent les preuves et les conditions de chaque essai, y compris ses échecs et ses limites. Leur numéro n'indique pas une fonctionnalité de production. Une attente ancienne peut avoir été résolue par une expérience ultérieure.

Pour savoir où en est le projet et quoi faire ensuite : [état des lieux](../ETAT_DES_LIEUX.md). Pour comprendre les composants : [architecture](../ARCHITECTURE.md). L'ancien journal inséré dans l'architecture est conservé dans [l'archive](../archives/ARCHITECTURE_HISTORIQUE_2026-11-25.md).

L'ancien registre des questions ouvertes est aussi conservé dans [une archive datée](../archives/QUESTIONS_OUVERTES_HISTORIQUE_2026-11-25.md). Les synthèses actuelles priment sur ses attentes intermédiaires.

## Repères de lecture

- P12–P14 : stockage transactionnel et reprise, d'abord isolés.
- P16–P20 : assemblage jouable, HTTPS/WSS, cache et point d'accès local.
- P21–P23 : deuxième téléphone, incidents/reprise, échéance et Firefox.
- P24 : interface intégrée, recette 0.17 et préparation du podium partagé 0.18.

- P25 : comparaison des accès locaux sans autorité de laboratoire et première sonde de contexte sécurisé.
